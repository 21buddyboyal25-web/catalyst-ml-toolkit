# Project Plan: ML-Driven Modeling of Bimetallic Catalysts for CO2 Conversion

## 1. Project Goal
Develop an independent computational pipeline using Python, machine learning, graph neural networks (GNNs), DFT-derived data, and reaction-engineering principles to model and optimize core-shell bimetallic catalysts for selective CO2 conversion.

## 2. Core Repository Directory Structure
- data/: Raw and processed dataset storage
- 
otebooks/: Step-by-step Jupyter notebooks for EDA, data cleaning, baseline ML, GNNs, and optimization
- src/: Reusable Python modules for data processing, feature engineering, models, and evaluation
- models/: Saved model weights and artifacts
- esults/: Generated figures, evaluation metrics, and prediction outputs
- docs/: Project documentation and workflow tracking
